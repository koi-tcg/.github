# Contributing

Koi TCG is currently developed in private repositories.

- Open an issue before starting substantial work.
- Branch from `main`; do not commit feature work directly to the default branch.
- Keep pull requests focused and include validation evidence.
- Never commit credentials, customer data, card scans owned by customers, or
  payment-provider exports.
- Use conventional commit subjects such as `feat:`, `fix:`, `docs:`, and
  `chore:`.
- State data/security impact, rollout, monitoring, and rollback.

A change is done only when its acceptance criteria, tests, documentation, and
operational impact are complete and the required repository check passes.
