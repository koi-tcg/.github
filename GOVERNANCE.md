# Governance

- `0xMorph` is the sole organization owner during the prototype.
- Repositories default to private; `.github` remains public for the profile and
  community standards.
- Changes use issues, short-lived branches, pull requests, and passing CI.
- Squash merge only; force-pushes and default-branch deletion stay blocked where
  the GitHub plan can enforce them.
- Owner-only actions include membership, repository creation/deletion/transfer,
  visibility, billing, secrets, and security policy changes.

Before another developer joins, upgrade the GitHub plan if necessary, enforce
private-repository branch rules, review approval count, and document access and
offboarding. Before launch, move contact, billing, and recovery to Koi business
identity with at least two recovery owners.
